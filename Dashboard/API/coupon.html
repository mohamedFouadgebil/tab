API Endpoints

Create Coupon

POST Protected Route
Active
/api/v1/coupon/create-coupon

Create a new discount coupon. Allowed roles: Admin, Company, Doctor.

Get Coupons

GET Protected Route
Active
/api/v1/coupon/get-coupons

Retrieve the list of all coupons. Allowed roles: Admin, Company, Doctor.

Get Coupon

GET Protected Route
Active
/api/v1/coupon/get-coupon/:couponId

Retrieve detailed information for a single coupon using its couponId parameter. Allowed roles: Admin, Company, Doctor.

Update Coupon

PATCH Protected Route
Active
/api/v1/coupon/update-coupon/:couponId

Update coupon details using its couponId parameter. Allowed roles: Admin, Company, Doctor.

Delete Coupon

DELETE Protected Route
Active
/api/v1/coupon/delete-coupon/:couponId

Permanently delete a coupon using its couponId parameter. Allowed roles: Admin, Company, Doctor.

Check Coupon Validity

GET Protected Route
Active
/api/v1/coupon/check-validity/:coupon

Check whether a coupon code is valid and can be applied, using the coupon parameter. Allowed roles: Admin, User.
